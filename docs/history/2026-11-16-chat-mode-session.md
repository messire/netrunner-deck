## Чат-режим (вариант «п2»: Deck читает транскрипт Claude Code)

- Rust `transcript.rs`: чтение `~/.claude/projects/<cwd>/<session>.jsonl` построчно (хвост 2 МБ при
  открытии, потом только дельта по смещению), поллер размера 250 мс → `deck://transcript`;
  отсутствие файла = новая сессия, не ошибка. `transcript_mtimes` — время последнего сообщения.
- TS `transcript.ts`: парсер строк (user / assistant / tool_use+tool_result / system / title; sidechain и
  meta отбрасываются; slash-команды из `<command-name>` собираются обратно в `/имя аргументы`;
  continuation-сводка после сжатия контекста — отдельный тип `compact`), `ChatBuilder` —
  инкрементальная сборка ленты (новые объекты только у изменившихся элементов), `turnFooters`
  (`✻ 13s · done 23:54`), `backgroundTasks` (полный список фоновых агентов из незавершённых `Agent`).
- `ChatView.tsx`: пузыри (YOU справа/жёлтый, CLAUDE слева/зелёный, 80 % ширины, рамка 2 px по скосу),
  markdown через marked+DOMPurify с мягкими переносами, tool-вызовы карточками, серии из 2+ вызовов
  свёрнуты в `▸ N STEPS · Bash ×24 · Write ×7`, системные заметки, `MEMORY DEFRAG` для сводок сжатия
  (свёрнут до одной строки), таймстемпы везде, индикатор работы — спрайт из GIF пользователя
  (`assets/think-sprite.png`, 60 кадров, CSS steps) с glitch-разрывами; векторный вариант оставлен
  за флагом `THINK_MODE`.
- Ввод: своё поле → `pane.send_text` + Enter; Shift+Enter перенос; ↑/↓ история своих сообщений;
  Tab/клик по бейджу берёт подсказку CLI (ghost-текст читается из окна ввода pane, клики по нему
  проходят к курсору); `/` — автодополнение по харнесу (скиллы/команды проекта и личные + встроенные
  команды CLI, argument-hint из frontmatter, подсказка над полем пока вводятся аргументы); картинки —
  в pane уходит Alt+V (Windows) / Ctrl+V, CLI сам берёт из буфера; миниатюры над полем, ✕/Backspace
  убирает последнюю; меню CLI (AskUserQuestion, разрешения) — карточка с кнопками, выбор делается
  стрелками+Enter в самом CLI; показывается только при статусе blocked и только если список в самом
  низу экрана. Чип режима прав (`DEFAULT/ACCEPT EDITS/PLAN/BYPASS`) в шапке, клик = Shift+Tab.
  Панель под вводом — подсказки по клавишам, статусная строка CLI, список фоновых агентов.
- Переключатель CHAT/TERM в шапке pane; терминальный вид оставлен как запасной.
- В TerminalView: фокус идёт в поле ввода только когда оно есть (shell-pane печатал в скрытый элемент).

## Боковая панель и общее

- Шрифты: Oxanium (заголовки/вкладки/индикаторы), Golos Text (тексты), JetBrains Mono (техническое),
  из `@fontsource-variable/*`; размеры подняты на ~15 %, затем выровнены между Sessions/Harness/Uplink/Archive.
- Плашки/карточки/диалоги: рамка по скосу через два слоя (цвет рамки + заливка на 1 px внутри) —
  CSS-border срезался clip-path'ом. Вкладки-параллелограммы.
- Sessions: репозитории жёлтым, worktree зелёным, легенда; сворачивание секций одинарным кликом с чипами
  сводки (Sessions: repo/worktree/session; Accounts: активный аккаунт 5H/7D; Session map: по статусам).
  `+` у SESSIONS — OPEN REPOSITORY (известные репо из Harness или путь), `+` у репо — NEW WORKTREE
  (`worktree.create`), `+` у worktree — NEW TAB (диалог «что запустить», по умолчанию CLAUDE).
  RENAME в меню пространства/таба/pane. `↓N/↑N` отставание веток (git локально, fetch каждые 5 мин).
- Session map: порядок по времени последнего сообщения (mtime транскрипта для Claude-pane, события
  вывода только для shell), цвета: красный working, жёлтый waiting, бирюзовый active (<15 мин),
  тёмный idle, рамка shell; плитки фиксированные, слева направо.
- Панели: левая и правая (QUICKHACKS) — минимум 320 px, максимум треть окна, обе тянутся; фоны
  привязаны к окну (`background-attachment: fixed`), левая — к верхнему левому углу шириной 1/3,
  правая — к верхнему правому, центр — cover.
- Титульная панель: счётчик агентов · AFTER LIFE · аккаунт с процентами (цвет = зона квоты) · часы.
- Все дочерние процессы (`claude -p`, `git`, открытие ссылок) — `CREATE_NO_WINDOW`; ссылки из чата
  открываются в системном браузере (`open_external`, только http/https), webview не уходит со страницы.

## Harness

- Вкладка HARNESS: Personal (`~/.claude`) + репозитории из Archive с теми же группами; разделы
  INSTRUCTIONS/SETTINGS/MCP/SKILLS/AGENTS/COMMANDS/RULES; просмотр файла справа (markdown/raw).
- Frontmatter: `description`, `tags`, `argument-hint`; кэш по (mtime, len). CLASSIFY — один
  `claude -p --model haiku` на репо, теги записываются в frontmatter файлов (`tags: [...]`), после чего
  Claude больше не вызывается. Облако тегов одно на весь харнес, теги — переключатели (жёлтые);
  текстовый поиск теги не трогает. `harness_read/classify` пишут/читают только под просканированными корнями.

## Quickhacks

- Правая панель с закреплёнными скиллами/командами (`quickhacks.json`). ADD: источник › репо › запись
  (с поиском). Запуск: репо › worktree (Herdr `worktree.list`) › агент (CLAUDE) › аргументы с
  argument-hint › Rust открывает/переиспользует пространство (`open_session_dir`: таб в открытом,
  иначе `worktree.open` — root и linked одинаково, fallback `workspace.create`), ждёт промпт shell,
  печатает `claude`, ждёт `❯`, отправляет `/имя аргументы`; прогресс — `deck://quickhack`.
- Тот же `open_session_dir` использует restore в Archive (корневая сессия возвращается в ROOT-пространство,
  а не отдельной папкой); при restore первому табу возвращается сохранённое имя; имена табов
  показываются в Archive и участвуют в поиске.
