# Идеи развития

Список возможных фич, не план и не обязательство. Основа — `docs/plan/ROADMAP.md` и `ROADMAP-own-runtime.md`.

## Рантайм
- Собственный сервер вместо Herdr: Rust, tokio, ConPTY, VT-состояние на `alacritty_terminal`.
- Статус агента из хуков Claude Code и транскрипта, а не по экрану.
- Удалённые машины: подключение к серверу по SSH, измерение `machine` в дереве.

## Панели и сессии
- Split view: две панели рядом.
- Правила рамок диалога для Codex и других агентов.
- Поиск по выводу панели и по архиву сессий.
- Экспорт сессии в Markdown.
- Звук при переходе агента в ожидание.

## Наблюдаемость
- Контроль активных соединений с сервером и их состояния.
- Мониторинг памяти и CPU процессов агентов, предупреждение об утечках.
- Расход токенов и стоимость по сессиям.

## Платформа и выпуск
- Сборки для Linux и macOS, unix-ветки в CI.
- Подпись инсталлятора Authenticode.
- Настройки темы и шрифтов в UI.
